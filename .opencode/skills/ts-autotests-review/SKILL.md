# Инструкция по ревью кода

## Цель

Научиться писать качественные автотесты на TypeScript, соблюдая позитивные паттерны проектирования автотестов и best practices TypeScript. Также соблюдать чистоту кода и разделение ответственности между файлами.

## Порядок действий

1. Просканировать проект и структуру папок с помощью встроенных MCP-инструментов для экономии токенов и лучшего чтения.
2. Проанализировать проект и прочитать код.
3. Проверить код и проект с точки зрения архитектуры и паттернов проектирования.
4. Проанализировать возможные улучшения.
5. Написать результат анализа и ревью пользователю.

## Ограничения

- Без разрешения пользователя не писать код внутри проекта.
- При предложении улучшения описать, что можно улучшить, но не показывать код решения.
- Писать на русском языке.
